# Strikethrough

These examples run with the `strikethrough` extension enabled.
Every expected output agrees with the reference implementation
and with the engine, byte for byte.

```````````````````````````````` example
~~Hi~~ Hello, world!
.
<p><del>Hi</del> Hello, world!</p>
````````````````````````````````
