# Heading identifiers


These examples run with the `heading_identifiers` extension enabled. Every expected output agrees with the reference implementation and with the engine, byte for byte, except the divergences marked below: four identifier divergences (decision 0021) and four differences in the surrounding markup where the reference itself does not follow CommonMark; in the latter the heading identifiers still agree.

The reference is marked with marked-gfm-heading-id, the only real-world heading-identifier pipeline drivable end to end; its output over this battery is frozen in `tests/fixtures/heading_oracle.json`, generated by `tools/heading_oracle_probe.mjs`. The engine derives a heading's identifier from its decoded text content — GitHub's DOM text semantics — while the reference derives it from the heading's raw source text passed through an entity-eating unescape and a lazy tag-strip regex. The four divergences each trace to a non-conformance of the reference, not of the engine; see decision 0021 (`docs/decisions/0021-heading-ids-extract-dom-text.md`).

The `Ordinary Markdown is unchanged` examples show the engine's core CommonMark output (the 652-example core suite covers it); the extension only adds identifiers to headings.

Regenerate this file with `cargo run -q -p geist4-ext --example gen_heading_spec`.

## Raw HTML and entities

```````````````````````````````` example
# caf&eacute;
.
<h1 id="café">café</h1>
````````````````````````````````
Divergence from the reference (decision 0021): the reference's unescape deletes the named entity; the engine keeps the decoded text.

```````````````````````````````` example
# &lt;tag&gt;
.
<h1 id="tag">&lt;tag&gt;</h1>
````````````````````````````````

```````````````````````````````` example
# <!-- a > b --> title
.
<h1 id="title"><!-- a > b --> title</h1>
````````````````````````````````
Divergence from the reference (decision 0021): the reference's lazy tag strip stops at the comment's first `>` and leaks its tail.

```````````````````````````````` example
# <?php ?> code
.
<h1 id="code"><?php ?> code</h1>
````````````````````````````````
Divergence from the reference (decision 0021): the reference's tag strip never matches a processing instruction and leaks its inner text.


```````````````````````````````` example

 c> d
````````````````````````````````

Expected output differs from the reference outside the identifiers: marked keeps the paragraph's leading space; CommonMark strips leading and trailing whitespace from paragraph text and the engine follows CommonMark; the heading identifiers agree.

Divergence from the reference (decision 0021): the reference slugs the stripped text without trimming; the engine trims the extracted text.
